# Dynamic Order Emails
This plugin adds multiple custom payment gateways to your WordPress website and includes an automated email reminder system to help customers complete their pending payments.

## Payment Gateways
- Bank Transfer
- Cheque
- COD
- Cashapp
- Zelle
- Venmo
- ECheck

## Email Reminder System
The plugin sends automated email reminders to customers for pending payments. The reminders are sent at different intervals based on the payment method. The plugin also includes a feature to cancel scheduled emails when the order status is changed to shipped.
